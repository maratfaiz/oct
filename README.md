# OCTera

Веб-платформа для загрузки изображений (OCT-снимков) и получения аналитического «вердикта» с помощью ML-модели.

## Статус проекта

Backend (FastAPI) подключён к реальной модели анализа OCT-снимков — см. раздел "Разработка". Архитектура и часть технологий пока не зафиксированы окончательно, README будет расширяться по мере разработки.

## Идея

1. Пользователь загружает изображение через веб-интерфейс.
2. Изображение анализируется ML-моделью.
3. Пользователь получает результат анализа (вердикт) и может посмотреть историю своих загрузок.

Модель не обучалась с нуля — используется готовая предобученная модель. Дообучение на собственных данных (при необходимости) — следующий шаг, пока используется как есть.

## Планируемый стек

- **Бэкенд:** Python + FastAPI — удобен для интеграции с PyTorch/TensorFlow и для дообучения/инференса моделей.
- **ML:** [`bitfount/RETFound_MAE_OCT_CNV_DME_DRU`](https://huggingface.co/bitfount/RETFound_MAE_OCT_CNV_DME_DRU) — ViT-L (RETFound), дообученная на датасете Kermany под 4 класса: CNV, DME, DRUSEN, NORMAL. Точность ~85% на этом датасете. **Лицензия весов — CC BY-NC 4.0 (только некоммерческое использование)** — учитывать при выборе модели монетизации проекта.
- **Фронтенд, база данных, хранение файлов:** пока не определены.

## Справочные материалы

В проекте есть подробный research-отчёт по возможной архитектуре платформы, покрывающий:

- варианты стека фронтенда/бэкенда и хранения данных;
- API-контракты (загрузка изображений, получение статуса и результата анализа);
- варианты развёртывания и обслуживания ML-модели (TorchServe, TensorFlow Serving, Triton и др.);
- CI/CD и контейнеризацию;
- стратегию тестирования;
- безопасность, конфиденциальность и соответствие требованиям (GDPR/ПДн);
- наблюдаемость (логи, метрики, алерты, SLO).

Он используется как справочный материал при принятии архитектурных решений, но сам по себе не фиксирует финальный выбор технологий.

## Разработка

### Backend

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/uvicorn app.main:app --reload
```

Эндпоинты: `POST /api/images/upload`, `GET /api/images/{image_id}/status`, `GET /api/images/{image_id}/result`, `GET /api/health`.

При первом вызове анализа веса модели (~2 ГБ) скачиваются с Hugging Face и кэшируются локально — первый запрос будет заметно медленнее следующих. Хранение результатов — в памяти процесса, без БД (см. `docs/PLAN.md`, этап 4).

Тесты: `.venv/bin/pytest tests/` (реальная модель в тестах подменяется заглушкой — тесты быстрые и не требуют сети).
